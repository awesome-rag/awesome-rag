## 2025.04
### ZettelForge
> Agentic memory for cyber threat intelligence. Entity extraction, STIX 2.1 knowledge graph, intent-classified blended retrieval. Offline-first.

* 时间：04.15
* 项目：[https://github.com/rolandpg/zettelforge](https://github.com/rolandpg/zettelforge)

ZettelForge is a domain-specific RAG system for cyber threat intelligence (CTI). It combines entity extraction with a STIX 2.1 knowledge graph and intent-classified blended retrieval (lexical + vector + HyDE). Designed for offline-first operation, it can be installed via `pip install zettelforge`.
